# PART 7 — ការដោះស្រាយបញ្ហា (Troubleshooting Guide)
 
## 7.1 បង់ប្រាក់រួច តែ Diamonds មិនចូល
1. បិទ និងបើកហ្គេមឡើងវិញ (Restart)។

4. ពិនិត្យម៉ោងសេវា (8:00 AM – 10:00 PM) — ក្រៅម៉ោងអាចយឺត។
5. បើនៅតែមិនបាន សូមផ្ញើ Screenshot វិក្កយបត្រ + ID + ឈ្មោះហ្គេម + កញ្ចប់ ទៅ Admin។
 
## 7.2 ប៊ូតុង "Check ID" បង្ហាញថា ID មិនត្រឹមត្រូវ
1. ពិនិត្យលេខ ID ម្តងទៀត (កុំមានដកឃ្លា ឬអក្សរលើស)។
2. សម្រាប់ Mobile Legends ត្រូវបញ្ចូលទាំង User ID និង Zone ID។
3. ចម្លង (Copy) ID ពីក្នុងហ្គេមដោយផ្ទាល់ ដើម្បីជៀសវាងវាយខុស។
4. បើនៅតែមិនបាន សូមទាក់ទង Admin។
 
## 7.3 មិនអាចស្កេន QR បាន

2. បង្កើនពន្លឺអេក្រង់ ហើយស្កេនម្តងទៀតតាម ABA Mobile។
3. បើ QR ផុតកំណត់ សូមបង្កើតការបញ្ជាទិញថ្មី។
4. បើមិនអាច សូមសាកល្បងវិធី Aceleda ឬទាក់ទង Admin។
